# POPJIA Toon Toolbox

欢迎使用 POPJIA 的卡通渲染辅助工具箱。

## 当前包含工具

点击下方工具名称即可在浏览器中直接使用：

- [Normal Fixer](https://popjia.github.io/ToonTools/NormalFixer/)：快速修复卡通角色法线朝向与平滑度。
- [SDF 通道序列拆解](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_Frame_Painter.html)：将 SDF 通道序列按角度拆解，并导出对应帧。
- [SDF 帧合成](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_Frame_Composer.html)：导入多帧 SDF 数据并合成为可用通道。
- [SDF RGBA 合图](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_RGBA_Packer.html)：批量导入通道图片，将它们打包成 RGBA 贴图。
