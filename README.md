# POPJIA Toon Toolbox

欢迎使用 POPJIA 的卡通渲染辅助工具箱。

## 当前包含工具

点击下方工具名称即可在浏览器中直接使用：

- [Normal Fixer](https://popjia.github.io/ToonTools/NormalFixer/)：修复游戏解包后通道异常导致发红的法线贴图。
- [Normal Map Inspector](https://popjia.github.io/ToonTools/TextureTools/Normal_Map_Inspector.html)：检查法线贴图方向、通道分布与可视化预览。
- [Normal DX / OpenGL Switcher](https://popjia.github.io/ToonTools/TextureTools/Normal_DX_OpenGL_Switcher.html)：在 DirectX 与 OpenGL 法线格式之间快速转换。
- [Texture Channel Curve Tool](https://popjia.github.io/ToonTools/TextureTools/Texture_Channel_Curve_Tool.html)：按通道调整贴图曲线，并查看直方图与导出结果。
- [UV Edge Padding / Dilation](https://popjia.github.io/ToonTools/TextureTools/UV_Edge_Padding_Dilation.html)：为贴图 UV 岛边缘生成扩展像素，减少接缝漏色。
- [SDF 通道序列拆解](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_Frame_Painter.html)：将 SDF 通道序列按角度拆解，并导出对应帧。
- [SDF 帧合成](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_Frame_Composer.html)：导入多帧 SDF 数据并合成为可用通道。
- [SDF RGBA 合图](https://popjia.github.io/ToonTools/SDF_Frame_Painter/SDF_RGBA_Packer.html)：批量导入通道图片，将它们打包成 RGBA 贴图。
